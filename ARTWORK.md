# Artwork and branding

The Aika desktop wallpaper, mascot logo and GRUB background were created with integrated image generation using user-supplied Aika references for the [main AikaOS project](https://github.com/emiliaplays/AikaOS). The Fastfetch portrait/configuration was supplied by the maintainer.

Mini asset mapping to the original project:

- `assets/desktop.png`: `assets/branding/aika-desktop.png`
- `assets/aikaos-logo.png`: `assets/branding/aika-logo-v2.png`
- `assets/background.png`: `assets/grub/background.png`
- `assets/fastfetch.jsonc`: `assets/fastfetch/config-compact.jsonc`

Original generation prompts are in the main repository under `assets/branding/prompts.json`, `assets/branding/desktop-prompt.txt` and `assets/grub/prompt.txt`.

The monochrome mascot in `assets/aika-logo-schwarzweiss.png` was generated from the original mascot for the paper CD sleeve. Its prompt is in `assets/aika-logo-schwarzweiss-prompt.txt`. The A4 sleeve layout is generated by `scripts/create-cd-sleeve-bw-aika.py`, requiring Python, ReportLab, pypdf, pypdfium2, Pillow and the Windows Arial fonts. Create an `out/` directory before running it. The printable PDF is in `print/`.
